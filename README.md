# focus.

A minimalistic personal task manager that runs in your browser.

## How to open it

**Desktop:** Double-click `index.html` — that's it. No installation needed.

**Phone (PWA):** Host the folder online (e.g. Netlify or GitHub Pages), open the URL in Chrome or Safari on your phone, then tap "Add to Home Screen". The app installs like a native app.

## How to use it

- **Areas** — your task categories (Career, Health, Music, Bachata, Misc). Add your own with "Add area".
- **Tasks** — tap "+ New" to add one. Give it a title, pick an area, and choose This Week, Later, or Habit.
- **This Week** — your weekly focus view. Shows all habits + tasks flagged for this week.
- **Completed** — marking a task done moves it here, out of your way.
- **Reorder** — drag tasks up or down in any view using the ≡ handle on the right of each card.
- **Habits** — recurring items with a counter (e.g. 3 / 6). Tap to log progress. They reset automatically every Monday. When the target is reached the card shows as done.

## Your data

Everything is saved automatically in your browser (localStorage). No account, no server.

Long-press "focus." in the sidebar on desktop to export or import a JSON backup. On mobile, tap the "focus." link that appears in the header when on the This Week view.
