# focus.

A minimalistic personal task manager that runs in your browser.

## How to open it

**Desktop:** Double-click `index.html` — that's it. No installation needed.

**Phone (PWA):** Host the folder online (e.g. Netlify or GitHub Pages), open the URL in Chrome or Safari on your phone, then tap "Add to Home Screen". The app installs like a native app and works offline.

## How to use it

- **Areas** — your task categories (Finances, Health, Social, Job, Misc). Add your own with "Add area".
- **Tasks** — click "+ New task" to add one. Give it a title, optional description, and pick an area.
- **This Week** — flag any task with ◇ to add it to your weekly focus view.
- **Completed** — marking a task done (✓) moves it here, out of your way.
- **Reorder** — drag tasks up or down within any area view or the This Week view.
- **Weekly Goals** — recurring goals with a counter (e.g. 3 / 6). Hit `+` each time you make progress, `−` to undo a mistake. They reset automatically every Monday. Create them with `+ New goal` in any area or This Week view.

## Your data

Everything is saved automatically in your browser (localStorage). No account, no server, no internet needed.
